# Proyecto modular universidad
## TheraPose

Se desarrollo una aplicación Python de escritorio utilizando el framework CustomTkinter y encapsulada con Docker, la cual hace uso de la base de datos no relacional MongoDB para el control y registro de pacientes en la terapia física, y cuenta con juegos interactivos 2D para ayudar en la rehabilitación física de los pacientes.

La interacción con los juegos 2D para la rehabilitación se lleva a cabo por medio de dos cámaras de bajo costo, de modelos de deep learning para la estimación 2D de puntos característicos del cuerpo y de la visión estéreo para obtener una representación en 3D del paciente.
